0 · 시작하기 전에

깃허브(GitHub)는 파일을 올려 두는 인터넷 서랍입니다

우리는 이 서랍에 HTML 파일을 올리고, 깃허브가 그 파일을 누구나 열어 볼 수 있는 웹 주소로 바꿔 주는 기능(GitHub Pages)을 씁니다.

내 컴퓨터의 index.html→깃허브 저장소에 올리기→Pages 켜기→https://아이디.github.io/저장소이름/
용어 3개만 알면 됩니다
용어뜻
저장소 (Repository, repo)프로젝트 하나를 담는 폴더. 파일과 수정 기록이 들어 있다
커밋 (Commit)"이 상태로 저장" 하는 것. 올릴 때마다 한 번 눌러야 반영된다
Pages저장소의 HTML을 웹사이트로 열어 주는 깃허브 기능 (무료)

이 자료의 화면은 2026년 11월 기준 영어 화면 캡처입니다. 깃허브 화면은 수시로 조금씩 바뀌므로 버튼 위치가 다르면 이름(영어)을 보고 찾으세요. 캡처의 아이디·사진은 가렸습니다.

1 · 가입하기

계정 만들기 — 무료 계정이면 충분합니다

주소창에 github.com을 입력해 들어가 오른쪽 위 Sign up을 누릅니다.

1
이메일 입력자주 쓰는 이메일. 인증 번호가 이 주소로 옵니다. (학교 메일도 가능)
2
비밀번호 입력15자 이상, 또는 8자 이상이면서 숫자와 소문자를 포함해야 합니다.
3
사용자 이름(아이디) 정하기나중에 웹 주소에 들어갑니다 → 영어 소문자·숫자·하이픈으로 짧게. 예: minsu-kim
4
"Verify" 퍼즐 풀기사람인지 확인하는 퍼즐입니다. 안내대로 그림을 맞추면 됩니다.
5
이메일로 온 인증 코드 입력메일함에서 숫자 코드를 확인해 입력하면 가입이 끝납니다.
화면 예시 (설명용으로 다시 그린 그림 — 실제 화면과 다를 수 있음)
name@example.com

주의 비밀번호는 다른 곳과 같은 것을 쓰지 말고, 다른 사람에게 알려 주지 않습니다. 사용자 이름은 나중에 바꾸기 번거로우니 가입할 때 신중히 정하세요.

3 · 저장소 만들기

HTML을 담을 새 저장소 만들기

오른쪽 위 + → New repository를 누르거나 주소창에 github.com/new를 입력합니다.

항목입력 방법
Repository name영어 소문자와 하이픈 (예: my-first-page). 한글·공백은 피한다
Description비워 두어도 된다
Public / PrivatePublic으로 둔다 (무료 계정의 Pages는 공개 저장소에서 쓴다)
Add README끄고 넘어가도 되고, 켜도 된다 (켜면 업로드 화면이 바로 열려 더 쉽다)

맨 아래 초록색 Create repository를 누르면 저장소가 만들어집니다.

팁 README를 켜고 만들면 저장소가 처음부터 "비어 있지 않은 상태"라 다음 단계의 Add file → Upload files 메뉴가 바로 나타납니다. 끄고 만들었다면 아래 4단계의 "빈 저장소" 안내를 보세요.
4 · HTML 올리기

내 HTML 파일을 끌어다 놓고 저장(커밋)

먼저 확인 올릴 파일 이름을 index.html로 바꿔 두세요. 웹 주소만 열었을 때 첫 화면으로 보이는 파일 이름이 index.html입니다. 영어 소문자로 써야 합니다.
1
저장소 화면에서 Add file → Upload files저장소 위쪽의 Add file 버튼을 누르면 메뉴가 열립니다.
2
파일을 끌어다 놓기"Drag files here" 상자에 index.html을 끌어다 놓거나, choose your files를 눌러 선택합니다.
3
Commit changes아래쪽 Commit changes(초록 버튼)를 누르면 올라갑니다. 위의 입력칸(커밋 메시지)은 비워 두어도 됩니다.
저장소를 "빈 상태"로 만들었다면?

빈 저장소에서는 Add file 메뉴 대신 Quick setup 안내가 나옵니다. 거기 있는 uploading an existing file 링크를 누르면 같은 업로드 화면이 열립니다.

올린 뒤 저장소 화면에 index.html이 파일 목록에 보이면 성공입니다.

5 · 웹페이지로 켜기

GitHub Pages 켜기

저장소 위쪽 메뉴의 Settings → 왼쪽 메뉴의 Pages로 들어갑니다.

파일을 올리기 전에는 이렇게 "비활성(disabled)" 상태로 보입니다.

1
Source는 Deploy from a branch 그대로 둡니다.
2
Branch를 None → main(또는 master)으로 바꾸고, 폴더는 / (root)를 고릅니다.
3
Save를 누릅니다. 1~2분 기다린 뒤 새로고침하면 위쪽에 주소가 나타납니다.
알림 화면 아래쪽 Visibility(GitHub Enterprise)와 "Start free for 30 days"는 유료 체험 안내입니다. 누르지 않아도 됩니다.
6 · 주소 확인

내 페이지 주소는 이렇게 만들어집니다

https://내아이디.github.io/저장소이름/
  • 내아이디 = 가입할 때 정한 사용자 이름
  • 저장소이름 = 3단계에서 정한 Repository name
  • index.html 파일은 주소에 쓰지 않아도 첫 화면으로 열립니다

다른 HTML 파일(예: chart.html)을 같은 저장소에 올렸다면 주소 끝에 파일 이름을 붙입니다: …github.io/저장소이름/chart.html

확인 방법 주소를 휴대폰 브라우저에서도 열어 보세요. 다른 사람 화면에서도 열리면 성공입니다. 이 주소를 과제 제출에 사용합니다.
7 · 막혔을 때

자주 생기는 문제 4가지

증상확인할 것
주소를 열면 404 (페이지를 찾을 수 없음)파일 이름이 index.html(소문자)인지, 저장소 맨 앞(루트)에 있는지 확인. 켠 직후에는 1~2분 걸린다
Pages에서 Branch가 None만 보인다저장소가 비어 있다는 뜻. 먼저 파일을 올린다
화면이 글자만 나오고 모양이 안 나온다이미지·CSS 파일을 같은 저장소에 같이 올렸는지, 파일 이름 대소문자가 같은지 확인
수정했는데 예전 모습 그대로수정본을 다시 올리고(같은 이름이면 덮어쓰기) 1~2분 뒤 Ctrl+F5로 새로고침
수정본 다시 올리기 저장소에서 Add file → Upload files로 같은 이름의 파일을 올리고 Commit changes를 누르면 덮어씌워집니다.
